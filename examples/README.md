# Examples

| Folder | What it shows |
|---|---|
| [`onboard-office/`](onboard-office/main.tf) | A new office: members with invitation mails, the office server's setup code, grants to the office devices, a Beam-in code for the IT partner |
| [`hoster/`](hoster/main.tf) | A hoster: setup code -> cloud server with `cloud_init` -> wait for the device -> Beam-in code for the customer |
| [`managed-service-provider/`](managed-service-provider/main.tf) | A technician with access to two customer devices until the contract ends |
| [`cloud-init/`](cloud-init/cloud-config.yaml) | Without Terraform: a `#cloud-config` with the setup code |
| [`ansible/`](ansible/enrol.yml) | Without Terraform: an Ansible playbook that enrols hosts |
| `provider/`, `resources/`, `data-sources/` | The snippets in the Registry documentation (`docs/`, generated by `tfplugindocs`) |
